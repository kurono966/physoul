# PHYSOUL

ブラウザー版: https://kurono966.github.io/physoul/

「プレイ」で読み込み、ゲーム画面をクリックしてマウス操作を開始。Escで解除、再クリックで再取得。ゲームパッドも使用可能（認識のため最初にボタンを押す）。PC向けのためタッチ操作には未対応。

Web公開は `.github/workflows/pages.yml` がmainへのpushごとにGodot 4.6.3で自動ビルドし、GitHub Pagesへ配信する。リポジトリのSettings > PagesはGitHub Actionsを選択。シングルスレッド・Compatibility/WebGL 2で書き出すため特殊なCOOP/COEPヘッダーは不要。ローカル書き出しは `godot --headless --path . --export-release Web build/web/index.html`。書き出したファイルはHTTPサーバー経由で開く。

Godot 4.6 / GDScript。project.godot を開き F5 で起動。

## 操作

探索部屋の輪郭は横長・縦長・十字・L字（左右上下反転あり）・角を落とした八角形・寸法が変わる広間の6系統。敵・祠・門は各形状の中央の安全な床に置き、箱は壁に重ならない床だけに配置。部屋への進入判定とミニマップも実際の床形状を使用する。死亡した戦闘者は身体・盾・武器の当たり判定と残留速度をすべて解除し、死体は表示だけ残して通り抜けられる。

通常は8部屋と幅180pxの通路を持つ探索ダンジョンをシード生成する。安全な開始部屋から進み、通常敵の守護者を倒して印を3つ集め、最奥のボス門でE／Yを押すと別の開けた闘技場へ移動する。入口でHPを引き継ぐ。祠はE／YでHP50回復（探索ごとに1回）。部屋を移動しても敵HPと撃破状態を保持する。ミニマップは訪問部屋と隣接する通路を表示。M／十字キー上で新しい探索を開始、R／Startで同じステージ・シードをリトライ（HP全快）。ボス撃破後はE／Yで新しい探索へ。探索ロジックは scripts/dungeon_generator.gd、ボスの闘技場生成は scripts/map_generator.gd。ボス闘技場のみ従来の外周・柱・箱・中央戦闘空間を維持。テストでは random_map=false にして固定闘技場を使う。F3デバッグ中のみ数字1〜3で敵を交換、4でボスへ直行できる。

予備動作・攻撃タイミングの円形ゲージはF3デバッグ中のみ表示。通常時は振りかぶり・剣の引き・軌跡などで動作を表す。

Back/View（PS系のCreate/Share相当位置）で下部の操作説明を帯ごと表示切替。キーボードはH。LT/L2を押すと0.95秒の予備動作後に斜め斬り＋衝撃波。スタミナ38消費、衝撃波は速度520px/s・寿命0.8秒・35ダメージ・体勢負荷42。盾とジャストガードに対応し、壁や箱に当たると消える。押しっぱなしでは再発動しない。予備動作から硬直まで入力移動は停止し、体勢崩れ・武器反動で発生前に中断すると衝撃波も出ない。

パッド回避をA/×へ変更（B/○では回避しない）。RT/R2で強攻撃：押して構え、0.65秒未満で離すと縦斬り、押し続けると溜め縦斬りが自動発動して縦斬りの追撃へ派生する。短押し28、溜め40、追撃18のスタミナ消費。通常比のダメージ倍率は強攻撃1.5・溜め1.9、体勢負荷も増加。押しっぱなしで繰り返さず、武器反動・体勢崩れ・スタミナ不足で派生を中断。RB/R1の短押し横振り・長押し自動突きは継続。

コントローラー（Godot標準マッピング、Xbox / PlayStation相当位置）にも対応。左スティック移動、右スティック左右で視点、RB/R1短押しで横振り・長押しで自動突き・隣接した体勢崩れ敵へ致命、LB/L1でガードとジャストガード、A/×で回避、RT/R2で強攻撃、X/□で蹴り、R3でロックオン、Y/△で調べる・ボス門（十字キー右/Nも同じ操作）、Start/Optionsで再開始。倒し量によるアナログ速度と0.22のデッドゾーン。右スティック感度は view.gd の stick_turn_speed。操作案内は直前に使った入力に追従する。実機の接続・機種別マッピングは未検証、tests/controller.gd の模擬イベントで検証。

- WASD: カメラ基準移動
- マウス左右: 視点（感度 scripts/view.gd の mouse_sensitivity = 0.0012）
- 左クリック短押しして離す: 横振り
- 左クリック長押し: 押している間に剣を引いて構え、0.32秒で自動的に突く（離す必要なし）。押し続けても1回のみ。発動後に離しても横振りは出ない。
- 右クリック: ガード
- 右クリックで構えてから0.18秒以内の盾接触: ジャストガード。HPダメージ・防御側の体勢増加なし、スタミナ4消費。相手の武器をはじいて連撃中断、相手に体勢負荷60。体勢崩れから致命攻撃につながる。成功すると水色の閃光と専用表示。1回の構えで成功は1回、押し直しの再発動間隔0.45秒。押しっぱなしは通常ガード。タイミングは fighter.gd の just_guard_duration で調整可能。
- Shift: ローリング、Space: キック
- Tab / ミドルクリック: ロックオン
- E / Y: 祠・ボス門、M / 十字キー上: 新しい探索、R / Start: 現在ステージを再挑戦
- Esc: マウスキャプチャ切替、F3: デバッグ

マウス移動による武器操作と支点ガイドは廃止。攻撃軌道は自動だが、トルク・慣性・接触速度・盾や壁の反動は維持。突きは刀身を前進させて判定し、引き戻し時には突きダメージを与えない。

構え（長押し中）・攻撃・攻撃後の硬直・キック動作中は入力移動を即停止する。慣性による入力移動の残りも除去し、硬直終了後に再び移動可能。攻撃動作による武器の移動と被弾の押し返しは維持。攻撃中のローリング割り込みも無効。

## 敵

攻撃開始と連撃継続には武器の実リーチを共通利用する。剣盾兵は中心間85px、重槌兵104px、槍兵145px以内。範囲外なら接近し直し、壁や箱で遮られている場合も攻撃を開始しない。攻撃開始には相手へ向いていることも必要。開始済みの一振りは回避されても最後まで振るが、届かなくなった場合は次の追撃を出さない。

体勢崩れ中の敵には金色のひし形が表示される。65px以内に接近し、画面に「LMB / CRITICAL STRIKE」が出たら左クリックで致命攻撃。スタミナ20消費、0.35秒の構え後に100ダメージ、全体0.9秒と追加硬直0.35秒。攻撃中は入力移動・通常攻撃を停止。同じ体勢崩れのチャンスは一度だけ消費できる。壁や箱で遮られている場合、スタミナ不足、攻撃硬直中などは発動不可。

1. WARDEN: 剣盾、左右に切り返す3連撃
2. IRON MAUL: 重槌、高耐久、重い2連撃
3. NEEDLE: 槍、素早い間合い調整と3連続突き
4. THE HOLLOW REGENT: 大型ボス。HP650、半径36px、長さ150pxの大剣。近距離は予備動作1.15秒から2連撃、遠距離は1.25秒の構えから衝撃波。HP半分でUNBOUNDへ移行し、予備動作0.95秒の3連撃と扇状3連衝撃波を使う。ジャストガード・体勢崩れ・致命攻撃が有効。4キーで選択、または十字キー右/Nで通常3種の次に登場。撃破後は剣盾兵へ循環。

初撃の予備動作は剣盾0.55秒、重槌1.0秒、槍0.85秒。追撃はそれぞれ0.28秒、0.48秒、0.32秒。構え中は橙色のリングと先端マーカーを表示し、攻撃判定を無効にする。各打撃直前に狙いを固定。槍の速度240px/s。連撃ごとにスタミナ消費、体勢崩れ・反動・対象離脱で中断。連撃後の隙は剣盾・槍0.7秒、重槌1.15秒。撃破後2.5秒で次の種類が出現。交換時にプレイヤーは回復しない。

## 物理と調整

武器は制御された軌道にトルクと慣性を適用するハイブリッド方式。120Hz物理更新と約2px刻みの軌道分割、刀身の放射状レイと6点スイープで接触を検出。攻撃ごとの対象IDで多重ヒットを防止。厳密な連続剛体シミュレーションではなく、極端な速度・薄い独自コライダーへの完全なCCD保証はしない。

盾は通常接触約3発、強打約2発でスタミナ枯渇（角度と回復で変化）。防御被弾後1.6秒は回復停止、枯渇時1.6秒ガード崩れ。押し返しは移動入力と独立して減衰。木箱の重力は無効化。

scripts/weapon.gd のexport変数で質量・長さ・角速度・トルク・ダメージ・反動を調整。fighter.gd は資源・行動・AI、view.gd は入力とカメラ、arena.gd は環境、hud.gd はHUD。

効果音は scripts/sound.gd が生成するオリジナルPCM。11種類、最大12音同時再生、volume_db（初期値 -8dB）で調整。ジャストガードは専用の0.72秒の澄んだD/A/D和音と短い金属のアタック音。音程のランダム化をせず成功音を一定に保つ。tests/audio.gd に -- --just-guard を渡すと専用音だけを再生し、just_guard_preview.wav を保存する。

## 検証

Godotの --script で tests/smoke.gd（戦闘）、tests/combo.gd（連撃）、tests/crate.gd（箱）、tests/audio.gd（音声）を実行。tests/click_input.gd と tests/enemies.gd はマウスキャプチャを使うため通常ウィンドウで実行。tests/preview.gd は preview.png に描画保存。

RT縦斬りは2Dのまま仮想的な持ち上げ角を計算し、投影した刀身の縮み・太さ・明るさと地面の影で遠近感を表現する。高く構えている間は当たり判定を無効化し、叩き下ろす0.18秒間のうち地面に近づいた区間だけ、伸びる正面の刀身をスイープする。横振りの範囲は使わない。

RTの振り下ろし開始に合わせて0.16秒の踏み込みを行う。通常28px・溜め42px、追撃にも通常分の踏み込みがある。予備動作・硬直中は踏み込まず、振り始めた方向へ固定。入力移動とは独立した攻撃速度として move_and_slide に渡すので、壁・箱・敵に衝突する。weapon.gd の heavy_step_distance / charged_step_distance で距離を調整できる。
